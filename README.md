# SPORTS AI Website V2.6

V2.6 adds live prediction tracking.

## New
- Track any prediction with one tap.
- Saved predictions persist on the user's device.
- My Predictions section.
- Tracked count, wins, losses, pushes and win percentage.
- Backend WIN/LOSS/PUSH evaluation is displayed when available.
- Pending predictions remain pending until V24 evaluation supplies a result.
- Untrack predictions anytime.

The website remains connected to the V24 backend and never stores the SportsDataIO API key in the browser.
