# SPORTS AI Website V2.9

V2.9 polishes prediction tracking and adds a SPORTS AI accuracy dashboard.

## New
- Clean prediction card action area with no duplicate tags.
- My Predictions tracker remains persistent on-device.
- Performance dashboard with tracked win rate, tracked/decided counts, wins and losses.
- Accuracy by NBA, MLB, NHL, NFL and Soccer.
- Dashboard updates automatically as tracked predictions receive WIN/LOSS/PUSH results from V24.
- Mobile-friendly layout.

Backend remains connected to the V24 backend. No SportsDataIO API key is stored in the website.
